# 页面与外观

## 页面模式

### 大封面模式

进入页面时显示完整壁纸。向下滚动后，壁纸继续作为页面背景，卡片区域在其上方展示。封面可以显示 Banner，并且最多选择一个分组；封面分组不显示分组标题，卡片保持居中。

向下引导箭头仅在鼠标移动到对应区域时显示。

### 列表模式

直接显示 Banner 与卡片列表，同时保留背景图片。页面底部不会额外留白。

## 卡片组布局

卡片组支持两种页面布局，可在“设置 → 外观 → 卡片组布局”中切换：

- 纵向分组：按排序依次展示所有分组和卡片。
- Tabs 切换：顶部显示“全部”和各分组标签，选择具体分组后仅展示该组卡片；“全部”模式仍展示完整分组，便于浏览和编辑。“全部”标签可单独关闭，关闭后页面默认选中第一个可见分组。

每个分组的“标题、图标、备注”或“仅图标”显示设置保持独立，不受卡片组布局影响。大封面模式中单独放入封面的分组不会重复出现在滚动后的 Tabs 中。

## 卡片与搜索框

搜索框可以单独显示或隐藏。卡片和搜索框共用一组透明度与圆角设置，可在外观设置中统一调整；圆角范围为 `0-32px`，透明度最高为 `0.9`。

## 壁纸

默认壁纸为项目内置的 WebP 图片。可以填写多张壁纸进行轮换，也可以上传 AVIF、PNG、WebP、JPG、JPEG 或 GIF 图片，单个文件最大 20 MB。上传后的文件名包含原始文件名和内容 Hash，方便辨认并避免同名覆盖。

壁纸遮罩默认值为 `0.20`。设置页修改遮罩时，壁纸预览会立即同步效果。

## 主题色

可以在“设置 → 外观 → 站点与页面”中通过推荐色板、颜色选择器或十六进制颜色值修改主题色，预览会立即应用到按钮、开关、标签和强调状态。系统会针对浅色、深色主题分别调整颜色亮度，保证文字和控件具备足够对比度。

点击“从壁纸选取”会对当前壁纸进行采样，忽略过暗、过亮和低饱和区域，并选择占比较高、辨识度较好的颜色作为主题色。远程壁纸需要允许浏览器跨域读取；本地上传的壁纸可以直接取色。

## Banner

Banner 可整体显示或隐藏，并可组合以下内容：

- 自定义标题
- 当前时间，可选择是否精确到秒
- 日期和周几
- 自定义一句话

大封面模式和列表模式分别适配 Banner 的可用空间，在小屏幕上会自动换行。

## 其他设置

- 网站标题与站点图标
- 浅色、深色或跟随系统主题
- 右上角环境切换和设置按钮仅悬停时显示
- 最多四行自定义页脚
- Google、Bing、GitHub 等搜索引擎及自定义搜索模板

搜索引擎模板使用 `{query}` 表示关键词，例如：

```text
https://www.google.com/search?q={query}
```
