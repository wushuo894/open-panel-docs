# Web 服务扫描

Web 扫描用于发现指定 IP 或域名开放的网页服务。该功能只允许已登录管理员使用。

::: warning 授权范围
只扫描你拥有或已获得明确授权的主机。端口扫描可能触发目标网络的安全告警。
:::

## 扫描步骤

1. 打开设置中的 Web 扫描。
2. 目标默认填入当前页面的 IP 或域名，也可以手动修改。
3. 使用滑动条选择 `80` 到 `65535` 范围内的起止端口；数字只在操作滑动条时显示。
4. 开始扫描，等待结果逐步返回。
5. 从结果列表选择服务并添加卡片。

## 结果筛选

扫描结果只保留返回 HTTP 200 且内容为 HTML 的服务，并自动跳过 Open Panel 自身。系统会尽量识别：

- 页面标题
- 站点图标
- 页面简介
- 内网 URL 与公网 URL

部分站点依赖 JavaScript 动态写入标题或禁止抓取元数据，这类结果可能需要手动补全。
