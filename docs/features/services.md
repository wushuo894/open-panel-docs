# 软件服务

软件服务卡片始终可以作为链接打开。填写 API Key 后，Open Panel 会在首页加载时向服务端 API 请求一次摘要；状态不会定时轮询。

## 支持的服务

| 服务类型 | 鉴权信息 | 卡片摘要 |
| --- | --- | --- |
| 通用服务 | 无 | Web 连通状态与响应耗时 |
| Emby | API Key | 播放与转码状态 |
| ani-rss | API Key | 订阅与下载任务 |
| qBittorrent | API Key | `版本 · 下载数 · 做种数` |
| OpenList | API Token | 存储总大小与存储数量 |

## 地址设置

内网 URL 和公网 URL 决定卡片点击后的目标地址。通用服务还可以单独填写“状态检测 URL”；其他服务使用当前可访问地址请求对应 API。

将卡片类型切换为软件服务，或在不同服务类型之间切换，不会覆盖已填写的标题、备注和内外网 URL。

## API Key 安全

API Key 由 Open Panel 后端保存并请求目标服务，不会随公开面板配置返回浏览器。配置导出文件包含这些凭据，应按敏感文件保管。

## 状态加载

系统信息、软件服务和 Docker 状态分别由独立接口加载。多个软件服务在服务端并行探测，某个响应较慢的服务不会阻塞系统信息或 Docker 卡片。

如果浏览器能够打开服务但卡片显示连接失败，请确认运行 Open Panel 的服务器本身可以解析该域名并访问目标端口。浏览器和服务器可能使用不同的 DNS、代理或网络路由。
