# 分组与卡片

分组用于组织首页内容。设置页负责新建、编辑、启用和排序分组；管理员可在首页编辑模式中新增、编辑、删除并拖拽卡片。

## 分组显示方式

每个分组可独立选择：

- **仅图标**：适合高密度的常用链接。
- **详细信息**：同时显示图标、标题和备注。

分组标题区域不显示卡片数量。分组和卡片均可调整顺序，卡片支持在同一分组内排序，也支持拖动到其他分组。

## 卡片类型

### 自定义链接

可分别填写内网和公网 URL，并选择在当前窗口或新窗口打开。输入链接后可自动获取网站标题、简介和图标；图标也可以从 MDI 列表选择、填写图片 URL 或上传本地图片。

### 系统信息

支持 CPU、内存、网络和存储指标。存储指标需要填写一个文件夹路径，卡片会显示该路径所在分区的已用容量与总容量。

系统信息卡片只展示指标，不作为页面链接。

### 软件服务

软件服务卡片兼具导航和状态摘要。可分别填写内网、公网 URL；未配置专属鉴权时仍会进行通用 Web 探活。详见[软件服务](/features/services)。

### Docker

绑定一个 Docker 容器后显示运行状态和运行时间。管理员悬停卡片时，可在右下角启动、停止或重启容器。详见[Docker 容器](/features/docker)。

## 内外网切换

首页右上角使用一个按钮切换内网和公网环境。可跳转卡片会优先打开当前环境对应的 URL；如果当前环境未填写地址，则使用另一侧可用的地址。

## 图标来源

卡片图标支持三种来源，编辑时可随时切换且已填写内容会被保留：

1. 从可搜索的 MDI 图标列表选择。
2. 填写自定义图片 URL。
3. 上传本地图片。

本地图标支持 AVIF、PNG、WebP、JPG、JPEG、GIF、SVG 和 ICO，单个文件最大 2 MB。

透明图标会在独立图标容器内渲染，避免与后方内容重叠。
