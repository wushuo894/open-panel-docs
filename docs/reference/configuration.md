# 配置说明

Open Panel 的服务端配置默认保存在 `config/open-panel.json`。建议优先通过设置页修改，不要在服务运行时直接编辑文件。

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `SERVER_PORT` | `57788` | 后端监听端口 |
| `OPEN_PANEL_CONFIG_DIR` | `./config` | 配置及上传资源目录 |
| `DOCKER_HOST` | 自动检测 | Docker 守护进程地址 |
| `TZ` | 系统时区 | 容器时区，建议明确设置 |

## 配置导入与导出

设置页支持导出完整 ZIP 备份，也可以上传 ZIP 文件恢复。备份包含 `open-panel.json` 以及配置引用的已上传背景图和卡片图标，适合备份或迁移实例。导入时会校验 ZIP 文件签名、目录结构、条目数量、解压大小和资源扩展名，并拒绝目录穿越路径。

导出内容包含：

- 页面、分组、卡片与搜索引擎配置
- 登录与 JWT 设置
- 软件服务 API Key
- GitHub Token
- 已上传的背景图和卡片图标

因此导出文件应加密保存，并限制读取权限。

## GitHub Token

更新检查使用 GitHub Releases。未认证请求容易受到共享公网 IP 的频率限制，可在更新设置中填写 GitHub Token。管理接口只返回脱敏值，但 Token 会写入本地配置文件。

## 前端路径

Open Panel 前端与本文档站都支持相对路径。通过反向代理挂载到子路径时，应同时确保 API 路径被代理到 Open Panel 后端。
