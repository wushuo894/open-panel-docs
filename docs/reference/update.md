# 更新与升级

进入“关于”页面时，Open Panel 会自动检查 GitHub Releases。也可以在设置页手动检查，并填写 GitHub Token 避免匿名请求受到共享 IP 的频率限制。

## Docker 部署

Docker 部署可直接在关于页面安装更新。Open Panel 会下载并校验 GitHub Release JAR，在容器内替换程序后由启动脚本重启 Java 进程，不需要重建当前容器。

也可以通过镜像完成完整升级：

```bash
docker compose pull
docker compose up -d
```

## JAR 部署

非 Windows、非容器环境可以在设置页安装更新。更新过程会校验发行文件的 SHA-256，完成后替换程序并重启。

## v1.0.1

### 新增

- 设置中新增按 Docker 可用状态显示的容器管理页，支持项目启动后及每 3 小时自动检测镜像更新；检测不会自动更新容器，支持更新的容器可随时从页面手动更新。
- Docker 页面支持启停、重启容器，并可查看和复制由当前容器配置生成的 `docker-compose.yaml`。
- Docker 页面显示容器运行时间，并支持清理未使用镜像及统计释放空间。
- 容器镜像支持 Hash Tag 暂存与切换、一键重建、实时进度、操作日志、中断和失败回滚。
- 软件服务新增 OpenList，可通过 API Token 展示存储总大小和存储数量。
- 软件服务与 Docker 卡片支持从链接自动补全标题、简介和网站图标。
- 选择 Docker 容器时，可使用容器名称同步卡片标题。
- 系统信息指标变化时，可自动同步默认标题。
- 首页拖动卡片增加实时占位预览，支持跨分组移动。

### 优化

- 重整卡片编辑弹窗，归纳基础信息、卡片内容与图标来源。
- 切换卡片类型时保留标题、备注和内外网 URL。
- Docker 卡片与普通卡片保持相同高度，操作按钮移至悬停时显示的右下角。
- GitHub Release 自动读取项目更新说明。

### 修复

- 修复部分正常网站被错误判断为连接失败的问题。
- 修复部分链接自动补全收到空 HTTP/1.1 响应时失败的问题。
- 修复 OpenList 类型和 API Token 无法持久保存的问题。
- 修复首页编辑状态下导航区域出现多余横线的问题。
